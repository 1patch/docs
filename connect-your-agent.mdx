The OnePatch plugin connects Claude Code, Codex, or Cursor to your workspace. The agent can query your telemetry with SQL, read the OnePatch agent's incident investigations, and start or reply to workspace chats. Everything is scoped to your organization. The only writes are starting a chat and replying to one.

## Install

The `onepatch` CLI wires every coding agent on your machine in one step.

```sh
npm install -g onepatch
onepatch install
```

Without Node, install the standalone binary instead:

```sh
curl -fsSL https://releases.onepatch.dev/install.sh | sh
```

`onepatch install` detects Claude Code, Codex, and Cursor and installs the OnePatch plugin in each. Pass an agent name to set up only one, as in `onepatch install cursor`. Each plugin can also be installed by hand.

<CodeGroup>

```sh Claude Code
claude plugin marketplace add 1patch/claude-code-plugin
claude plugin install onepatch@onepatch
```

```sh Codex
codex plugin marketplace add 1patch/codex-plugin
codex plugin install onepatch/onepatch
```

```text Cursor
/add-plugin https://github.com/1patch/cursor-plugin
```

</CodeGroup>

Codex also needs the MCP server in `~/.codex/config.toml`:

```toml
[mcp_servers.onepatch]
url = "https://app.onepatch.dev/mcp"
```

## Sign in

The first call opens an OAuth sign-in with your OnePatch account. In Claude Code, run `/mcp` to sign in. In Codex, run `codex mcp login onepatch`. In Cursor, sign in under Settings, MCP.

## Other clients

The plugin is a thin layer over the OnePatch MCP server. Any other MCP client, a script, or a CI job can connect to it directly. See [MCP](/mcp-server) for the endpoint, headless access with API keys, and the list of tools.
