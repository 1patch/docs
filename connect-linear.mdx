Connect Linear and the agent can read issues for context, create issues, and update them as it investigates. The workspace connection acts as **OnePatch**, so its writes are attributed to the app.

## Connect

On the **Integrations** page, find **Linear** and click **Connect**. A Linear workspace admin must approve the connection. The card shows the connected workspace when authorization completes.

The connection is available across your OnePatch workspace, including investigations started by monitors.

## Use it

Ask in chat or in an incident thread:

```text
Check Linear for known checkout timeout issues before investigating.
```

```text
Create a Linear issue in the Payments team with this incident's
findings and a link to the fix PR.
```

To remove the workspace connection, use **Disconnect** on the Linear card.
