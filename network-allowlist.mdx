---
title: Network allowlist
description: Limit which domains the OnePatch agent can reach.
---

By default the agent can reach any domain. To restrict it, go to **Settings › Networking** and enter domains under **Agent internet access**, one per line. Each entry also covers its subdomains. Leave the field empty to allow everything.

GitHub, the Anthropic API, and your OnePatch telemetry endpoint are always reachable.

Changes apply within a few minutes.
