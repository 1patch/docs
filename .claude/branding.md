# Brand artwork

Primary branding uses the supplied horizontal SVG lockup, including the
outlined wordmark. `docs.json` selects the black artwork on light backgrounds
and the white artwork on dark backgrounds. The footer uses the same files.

- `logo/onepatch-logo-light.svg`: black horizontal lockup.
- `logo/onepatch-logo-dark.svg`: white horizontal lockup.
- `logo/onepatch-favicon.svg`: coral symbol on a square canvas.

All previous artwork, including both PNG marks and the previous favicons, is
preserved in `logo/mascot/` for mascot use. Do not use it as the primary logo.

The SVG already includes the wordmark. Do not append a text wordmark to it.
