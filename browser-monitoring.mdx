Your backend says the request took 50ms. Browser monitoring says the person clicked **Save**, waited four seconds, and saw an error — and ties that to the server trace.

`@onepatch/rum` captures page views, clicks, `fetch` and XHR spans, JS errors and web vitals, each under a session id. There is no session replay: no DOM, no keystrokes, no form contents.

## Install

Take your ingest URL and token from **Workspace settings → integrations** — the same pair your backend uses. The token is write-only, so it belongs in your bundle the way a Sentry DSN does.

Paste this into your coding agent:

```text
Add OnePatch browser monitoring to this frontend.

First, install the setup skill (one-time):
npx skills add 1patch/skills -s rum-instrument

Then instrument the browser with the URL and write-only token.
Endpoint: https://your-org.logger.onepatch.dev. Token: op_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx.
```

It finds your entry point and auth path, wires identity, checks your backends' CORS, and records what it did in `TELEMETRY.md`.

Or by hand:

```ts
import { identifyUser, startRum } from "@onepatch/rum";

startRum({
  ingestUrl: "https://your-org.logger.onepatch.dev",
  ingestToken: "op_…",
  appName: "acme-web",        // <service>-web, named after your backend
  environment: "production",  // read it where your backend reads its own
  appVersion: commitSha,      // so you can ask "did the deploy do it?"
});

identifyUser({ id: user.id, email: user.email, orgId: user.orgId });
```

Call `startRum` once, early, on a client path. `identifyUser` is what turns sessions into people; put it wherever your app already knows who is signed in.

If your API is on another origin, list it — `connectTracesTo: ["https://api.acme.com"]`. Each origin is checked before trace headers are sent to it, so a backend with strict CORS costs you the correlation and never the request.

## Ask about it

Browser spans land beside your backend spans, so you ask in the same chat:

```text
The customer at deep@acme.com says the export button did nothing.
What did they actually do?
```

```text
Is the app slow for users right now, or just my handler?
```

Name your own steps with `recordAction("ran-workflow", { workflowId })`. Three to six on the paths that matter beats wrapping every button.

## Privacy

No DOM, no replay, no keystrokes, no form contents. Console capture is off by default.

URLs keep their query strings, because that is usually where the URL says *which* thing. Set `scrubQueryStrings: true` if yours carry reset tokens or email addresses rather than ids.

The package is Apache-2.0 and speaks plain OTLP: [github.com/1patch/rum](https://github.com/1patch/rum).
